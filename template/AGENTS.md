# Правила работы в этом проекте

## Режим работы: «обычно»

- В границах задачи действуй сам: выбирай способ реализации, правь вспомогательные файлы,
  если это прямо нужно запрошенному поведению.
- Ничего сверх задачи: ни фич, ни UI, ни анимаций, ни звуков, ни правок «заодно».
  Хочется — спроси. Новые зависимости и файлы — только после вопроса и ответа.
- В ответе перечисляй только фактически сделанное: «сделано по запросу», «потребовалось
  технически», «сделал сам в рамках задачи».
- Объясняй просто и коротко, но не в ущерб смыслу.
- «Строго» — только названные файлы и строки, любое отклонение — вопрос. «Свободно» —
  разумные улучшения в границах области, перечислить в ответе.

## Dev-сервер

- Сервер разработки уже запущен (порт 5173 у Vite) — используй его, свой не поднимай.
- Не запущен — спроси.

## PixiJS

- Перед любой правкой кода pixi.js загружай навык `pixijs` и работай по нему, а не по памяти.

## Анимации

- Если просят добавить анимации — делай их через `gsap`.
- Если анимация многоступенчатая (несколько последовательных анимаций) — используй `gsap.timeline()`, а не запуск следующей анимации внутри `onComplete()` колбэка.
- Если анимация подразумевает тикер и на `gsap` получается сложно — предупреди пользователя и используй тикер из PixiJS.

## Цвета

- Цвета во всём проекте пишем строками `"#ff00ff"`, а не числами `0xff00ff`.
